# VINAY_OS — Personal Developer Command Center

A cyberpunk-inspired personal portfolio with an interactive terminal and a playable Snake mini-game.

## Run locally

1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the **Live Server** VS Code extension.
3. Replace `YOUR_EMAIL@gmail.com` in `index.html` with your email address.
4. Update project links and descriptions in `index.html` as needed.

## Deploy with GitHub Pages

1. Push these files to your `vinay2005-lab` repository (or a separate repository if you prefer to keep the profile README repository clean).
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then click **Save**.
5. Wait for the Pages URL to appear. It will usually be `https://vinay2005-lab.github.io/vinay2005-lab/`.

## Important

GitHub profile README Markdown cannot run custom JavaScript. Host this website with GitHub Pages, then add a prominent link to it in the profile README.

No build tools or framework dependencies are required. The fonts are loaded from Google Fonts; the page still works with fallback fonts if they are unavailable.
